Файлы подтверждения прав в вебмастерах.

Всё, что лежит в этой папке, копируется в корень сайта как есть:
project/verification/yandex_1a2b3c.html → https://.../yandex_1a2b3c.html

Кладите сюда файл, который выдаёт панель:
  • Яндекс.Вебмастер — yandex_<код>.html
  • Google Search Console — google<код>.html

Этот README в сборку не попадает.

Альтернатива — мета-тег: вписать код в project/seo.config.json.
Достаточно одного из двух способов.
