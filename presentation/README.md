# Презентация «Даниил Карацапов — интернет-маркетолог»

Десять слайдов о себе как о маркетологе: путь, цифры, услуги, процесс,
кейсы, ниши, принцип, прайс, контакты. Все цифры взяты с сайта.

Живая версия лежит артефактом в Claude и правится там же. Здесь — исходники
слайдов и сборка PDF, чтобы презентацию можно было пересобрать без сервиса.

## Файлы

| Путь | Что это |
| --- | --- |
| `project/deck.json` | порядок слайдов, разделы, шрифты |
| `project/slides/<id>.html` | один слайд, один файл |
| `fonts/` | Manrope и Nunito Sans в woff2 + `local.css` |
| `make-pdf.mjs` | сборка PDF |

## Сборка PDF

```bash
node presentation/make-pdf.mjs
# → Карацапов-презентация.pdf в корне репозитория
```

Нужен `playwright-core` (он уже в зависимостях) и Chromium. Путь к браузеру
берётся из `CHROME`, по умолчанию — тот, что стоит в этом окружении.

## Про шрифты

Заголовки набраны **Manrope**, текст — **Nunito Sans**. Обе гарнитуры
поддерживают кириллицу, и это не мелочь: первая версия презентации была
собрана на Space Grotesk, у которого кириллицы нет вовсе, — все русские
заголовки молча подменялись системным Arial.

Если захотите поменять гарнитуру, проверяйте наборы символов до того, как
начнёте вёрстку:

```bash
curl -s "https://fonts.googleapis.com/css2?family=ИМЯ:wght@400;700" | grep -c cyrillic
```

Ноль означает, что кириллицы нет.

Обычно Chromium забирает шрифты с Google Fonts сам. Каталог `fonts/` нужен
для сборки там, где выхода в сеть нет: скрипт подхватывает `fonts/local.css`
и подставляет локальные файлы вместо ссылок.

## Формат слайда

Холст 1920×1080, поля 128 px, всё оформление — инлайновыми стилями из
ограниченного набора (без классов, `<style>`, `margin`, `em` и `var()`).
Один `<section>` на файл, последним потомком — `<aside>` с заметками
докладчика. Отрицательные отступы у приколотых элементов рантайм обрезает,
поэтому всё декоративное должно умещаться в холст.
