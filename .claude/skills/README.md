# Скиллы проекта

Подключаются автоматически в любой сессии по этому репозиторию — лежат в git,
поэтому переживают пересоздание контейнера.

| Скилл | Откуда | Зачем здесь |
|---|---|---|
| `ai-seo` | coreyhaines31/marketingskills | оптимизация под ИИ-поиск и обзоры |
| `content-strategy` | то же | планирование контента, кластеры тем |
| `copywriting` | то же | тексты для лендингов и услуг |
| `copy-editing` | то же | правка готовых текстов |
| `cro` | то же | конверсия страниц |
| `analytics` | то же | цели, события, разметка |
| `stop-slop` | hardikpandya/stop-slop | вычистка признаков ИИ-текста из прозы |

Лицензии: marketingskills — MIT (Corey Haines), stop-slop — репозиторий
Hardik Pandya.

## Почему не все 40

В marketingskills больше сорока скиллов. Взяты шесть, которые бьют в задачи
этого проекта. Чем больше скиллов, тем хуже они срабатывают: описания
начинают пересекаться, и подхватывается не тот. Нужен ещё какой-то —
скачивается одним файлом:

```
skills/<имя>/SKILL.md
из https://raw.githubusercontent.com/coreyhaines31/marketingskills/main/
```

Доступные имена перечислены в README того репозитория.

## Чего здесь нет

`ui-ux-pro-max` (nextlevelbuilder) собрать не удалось: он тянет каталог с
данными, а через прокси этого окружения недоступны ни архив репозитория, ни
GitHub API — перечислить имена файлов нечем. Ставится локально своим CLI.
