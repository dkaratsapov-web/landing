# Квадратные креативы под Яндекс Директ

Пять вариантов 1080×1080 для изображений в текстово-графических объявлениях
РСЯ. Собираются из `gen-direct.mjs`, правится только он.

```bash
node creatives/direct/gen-direct.mjs
```

## Что учтено из требований площадки

Соотношение 1:1 входит в допустимый диапазон, минимальная сторона — 450 px,
максимальная — 5000, вес до 10 МБ, форматы JPG/PNG/GIF. 1080×1080 и ~140 КБ
попадают в середину коридора: запас по чёткости на ретине есть, до лимита по
весу далеко.

На картинках нет телефона, почты и адреса сайта. Изображение в
текстово-графическом объявлении — не самостоятельный баннер, контактные данные
на нём вызывают вопросы у модерации, а пользы не приносят: кликают по
объявлению целиком.

Нет и превосходных степеней — «лучший», «№1», «гарантия результата». Это
одновременно риск по модерации и по 38-ФЗ: такие утверждения нужно уметь
подтвердить.

## Варианты

| Файл | Идея | Кому показывать |
| --- | --- | --- |
| `direct-1x1-01-zayavok-net.png` | «Реклама есть. Заявок нет» | тем, у кого кампании уже крутятся |
| `direct-1x1-02-pod-klyuch.png` | Директ под ключ, от 30 000 ₽/мес | тёплому спросу, кто ищет подрядчика |
| `direct-1x1-03-nishi.png` | 70+ ниш, опыт | недоверчивым, кто выбирает между агентством и частником |
| `direct-1x1-04-kuda-uhodit.png` | «Куда уходит бюджет?» | холодным, через боль |
| `direct-1x1-05-pod-klyuch-marketing.png` | Сайт, реклама, аналитика | тем, кому нужен не только трафик |

Варианты намеренно бьют в разные мотивы, а не переставляют слова: иначе тест
покажет разницу в оформлении, а не в оффере.

## Про макет

Композиция рассчитана на то, что в РСЯ картинку ужимают до трёхсот пикселей
по ширине. Отсюда заголовок в 108 px, две-три строки максимум и лайм только
на одном смысловом куске — при сжатии выживает именно он.

Шрифт Nunito вшит в `nunito-embed.css` в base64: системного Nunito в
окружении нет, без вшитого файла вёрстка молча уезжает на DejaVu.

Скриншот снимается в окне выше кадра и обрезается: у headless-Chromium вьюпорт
стабильно ниже `--window-size` примерно на 87 px, и нижняя строка иначе не
попадает в кадр.
